# CONCEPTION-ET-R-ALISATION-DE-L-APPLICATION-MOBILE-KWETU-PARK
La gestion du stationnement à Goma repose sur des pratiques informelles qui engendrent congestion, insécurité et perte de temps pour les automobilistes. Ce travail propose une solution logicielle mobile, nommée Kwetu Park, permettant la réservation en temps réel de places de stationnement et le paiement sécurisé via Mobile Money.
